## Identidad

La identidad está **declarada**, no vinculada criptográficamente: ningún perfil prueba por sí mismo que ambos handles sean la misma persona, aunque el contenido y las bios lo declaren. El registro canónico vive en `tamv-genesis/data/identity.json`.

## Qué no se incluye

- **Vertical restringida** (contenido para adultos): solo se usa como caso de arquitectura de gobernanza, derechos y cumplimiento. No se reproduce contenido ni se clona el repositorio.
- **Material de recuperación de cuentas**: excluido y marcado P0. Si algún archivo con credenciales estuvo expuesto, debe rotarse; borrarlo después no limpia el historial.
- **Forks de terceros**: no se copian ni se relicencian. Varios describen scraping, vigilancia o acceso remoto; se registran como forks, no como obra propia.
- **Contenido de repositorios**: este inventario usa metadatos públicos. No descarga ni publica el código de los repositorios listados.

## Regla de lectura

Un perfil de GitHub es **autopublicado** (tier T1). Sirve para establecer existencia, actividad y líneas de trabajo. No sirve para acreditar horas, adopción, calidad ni validación académica. Cualquier afirmación que cruce esa frontera se marca `unverified` en `tamv-genesis/data/claims.json`.

## Reproducir

```bash
gh api "users/OsoPanda1/repos?per_page=100&page=1" > /tmp/oso1.json
gh api "users/OsoPanda1/repos?per_page=100&page=2" > /tmp/oso2.json
gh api "users/AnubisVillasenor1/repos?per_page=100" > /tmp/anubis.json
gh api users/OsoPanda1 > /tmp/oso-user.json
gh api users/AnubisVillasenor1 > /tmp/anubis-user.json
node --experimental-strip-types tamv-genesis/scripts/profile-inventory.mjs \
  --input OsoPanda1=/tmp/oso1.json --input OsoPanda1=/tmp/oso2.json \
  --input AnubisVillasenor1=/tmp/anubis.json \
  --user OsoPanda1=/tmp/oso-user.json --user AnubisVillasenor1=/tmp/anubis-user.json \
  --write
```
