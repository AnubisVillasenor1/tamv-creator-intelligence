# LIMITATIONS.md

Esta versión final es una base de diseño y una herramienta de sellado.

No incluye:
- Servicios de producción desplegados.
- Claves privadas.
- Auditoría externa completada.
- Pruebas de penetración o certificación de seguridad.
- Garantía de cumplimiento normativo automático.
- Validación de titularidad de propiedad intelectual.
- Integración verificada con Skills.sh, Vercel, Supabase o proveedores externos.

La firma valida la integridad del paquete respecto de una clave pública.
No garantiza ausencia de vulnerabilidades, legalidad, autorización de
ejecución ni verdad de las afirmaciones contenidas.

Un hash no cifra datos. Un archivo local con hashes no es almacenamiento
WORM. Un skill no es una frontera de autorización.
