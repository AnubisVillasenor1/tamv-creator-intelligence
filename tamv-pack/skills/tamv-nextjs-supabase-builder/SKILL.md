# TAMV Next.js + Supabase Builder

## Propósito

Construir apps fullstack con Next.js, TypeScript, Tailwind y Supabase.

## Entradas requeridas

- requisitos funcionales
- modelo de datos y relaciones
- roles y reglas de acceso
- entorno de despliegue

## Reglas

- Validar permisos en servidor
- Usar RLS en todas las tablas
- Nunca exponer claves de servicio al cliente
- Tipar contratos de API

## Contrato de salida

- esquema de base de datos
- rutas y componentes
- políticas RLS y validación en servidor
- pruebas y notas de despliegue
