# TAMV Play & Go Architect

## Propósito

Diseñar arquitectura completa de PLAY & GO como Creator Operating System.

## Cuándo activarlo

Cuando se quiere crear educación musical, auditoría, contenido AI, monetización o plataforma de creadores.

## Entradas requeridas

- objetivos del producto y alcance del MVP
- usuarios y roles
- restricciones de infraestructura y presupuesto
- nivel de riesgo y datos tratados

## Reglas

- Diseñar con Next.js, Supabase, Stripe, Redis y Docker
- Mantener RLS y auditoría
- Usar Buffalo/BullMQ para trabajo asíncrono
- Diferenciar módulos Studio, Academy, Voice, Analytics y Support
- Usar MinIO para almacenamiento de media
- Mantener seguridad y trazabilidad

## Salida esperada

- arquitectura por módulos
- stack recomendada
- relación entre servicios
- modelo de datos
- plan de despliegue
- riesgos y mitigaciones
