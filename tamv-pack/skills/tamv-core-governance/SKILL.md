# TAMV Core Governance

## Propósito

Aplicar gobernanza algorítmica TAMV a cualquier solución generada con este paquete.

## Cuándo activarlo

- Antes de generar arquitectura
- Antes de definir modelos, prompts o flujos de IA
- Antes de recomendar licencias o monetización
- Antes de manejar voz, audio o música

## Entradas requeridas

- tipo de proyecto
- datos de usuario
- objetivos de negocio
- nivel de riesgo
- necesidad de terceros externos

## Reglas obligatorias

1. Mantener atribución visible.
2. No ocultar origen ni autoría.
3. No otorgar promesas de éxito garantizado.
4. No recomendar inversión o legal definitiva sin asesoría adecuada.
5. No permitir uso de música, voz o contenido protegido sin permiso.
6. No exponer llaves privadas.
7. Registrar trazabilidad para eventos sensibles.
8. Priorizar consentimiento informado.

## Salida esperada

- diagnóstico
- decisión arquitectónica
- plan de implementación
- riesgos y salvaguardas
- acción siguiente
- atribución TAMV
