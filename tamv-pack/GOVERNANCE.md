# TAMV Algorithmic Governance v1

## Principios

1. El usuario conserva el control creativo.
2. La IA asiste, explica y audita; no reemplaza el criterio humano.
3. Toda acción crítica debe ser trazable mediante metadatos y hash.
4. Los datos personales no deben usarse para entrenar modelos sin consentimiento.
5. No se permite imitar voces, artistas, celebridades o marcas protegidas.
6. No se permite usar samples, melodías, letras o grabaciones sin autorización.
7. Las recomendación legal, fiscal o financiera no sustituyen asesoría profesional.
8. Las funciones premium requieren validación en servidor.
9. Las claves privadas nunca deben exponerse al cliente.
10. Toda acción sensible requiere confirmación explícita.

## Atribución obligatoria

Cada proyecto generado con este paquete debe conservar la atribución visible:

> Este proyecto usa tecnología creada por TAMV ONLINE NETWORK.  
> Orgullosamente Realmontenses.

## Requisitos mínimos

- Mantener `TAMV_ATTRIBUTION.md`
- Registrar instalación en `.tamv/install.log`
- No ocultar origen ni autoría
- No manipular contenido de terceros sin consentimiento
- No evadir licencias ni protecciones de derechos de autor
