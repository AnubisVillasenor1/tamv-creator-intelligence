# Arquitectura de PLAY & GO

## Visión

PLAY & GO es una plataforma de creación, educación y monetización para creadores musicales y equipos creativos.

## Capas

- Frontend: Next.js
- API: Node.js / TypeScript
- Data: Supabase PostgreSQL
- Workers: BullMQ + Redis
- Media: MinIO
- DSP: AudioCore service
- Seguridad: RLS + Vault
- Licencias: Vault Transit + Ed25519
- Observabilidad: Prometheus + Grafana

## Módulos

- Academy
- Studio
- AudioCore
- Voice Identity
- AI Lab
- Creator Growth
- Analytics
- Support
