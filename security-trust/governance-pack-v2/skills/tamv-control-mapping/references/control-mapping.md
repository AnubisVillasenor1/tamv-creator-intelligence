# Control mapping reference

For every mapped criterion capture framework/version, exact criterion identifier and source URL, system boundary, period, services/exclusions, control owner, implementation evidence, evidence capture time, digest, classification, freshness, design assessment, implementation assessment, operating-effectiveness test, exceptions, residual risk, next test and reviewer.

NIST CSF 2.0 has six Functions: Govern, Identify, Protect, Detect, Respond and Recover. SOC 2 reports are based on a scoped independent examination. Mapping is not a SOC 2 report.
